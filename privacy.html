개인정보처리방침

YouTube Factory · 시행일 2026-11-02 · 홈

1. 개요

YouTube Factory(이하 "앱")는 운영자 본인의 YouTube 채널 운영을 위해 운영자 PC에서 실행되는 개인용 데스크톱 앱입니다. 앱은 YouTube API 서비스를 사용하며, 앱을 사용하면 YouTube 서비스 약관에 동의하는 것으로 간주됩니다. Google의 데이터 처리는 Google 개인정보처리방침을 따릅니다.

2. 접근하는 정보

  • 연결한 YouTube 채널 정보: 채널 ID, 채널 이름(youtube.readonly 범위). 어떤 채널이 연결됐는지 표시하는 데 씁니다.
  • 영상 업로드(youtube.upload 범위): 운영자가 자동 업로드를 켠 경우에만, 앱이 만든 영상과 썸네일을 연결한 채널에 비공개로 올리고 처리 상태를 조회합니다.
  • 공개 데이터 조회: 참고용 공개 채널과 영상의 공개 메타데이터(제목, 길이, 게시일, 조회수 등)를 조회해 영상 길이·구성 통계를 만듭니다. 영상 파일 자체는 내려받지 않습니다.

앱은 시청 기록, 구독 목록, 댓글, 연락처, 결제 정보 등 위 목적 외의 정보에 접근하지 않습니다.

3. 저장 위치와 보관

OAuth 토큰과 조회 결과는 운영자 PC의 앱 폴더에만 저장되고, 토큰은 운영체제 암호화(Windows DPAPI)로 보호됩니다. 앱 개발자나 제3자의 서버로 전송하지 않습니다. 공개 메타데이터로 만든 통계는 수치만 저장하며, 운영자가 앱 데이터를 삭제하면 함께 삭제됩니다.

4. 공유

앱은 Google 사용자 데이터를 판매하거나 제3자와 공유하지 않으며, 광고나 프로파일링에 사용하지 않습니다. Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 접근 권한 철회와 삭제

앱의 채널 연결 해제 기능을 쓰거나 Google 계정 → 타사 앱 액세스 권한에서 언제든 권한을 철회할 수 있습니다. 앱 폴더의 데이터를 삭제하면 저장된 토큰과 조회 결과가 모두 삭제됩니다.

Privacy Policy

Effective 2026-11-02

YouTube Factory is a personal desktop application that runs on the operator's own computer to produce videos for the operator's own YouTube channel. It uses YouTube API Services; by using it you agree to the YouTube Terms of Service, and Google's handling of data is governed by the Google Privacy Policy.

Data accessed: the connected channel's ID and title (youtube.readonly); uploading the app's own videos and thumbnails as private and checking their processing status, only when the operator enables automatic upload (youtube.upload); public metadata (title, duration, publish date, view count) of public reference channels to compute structural statistics. No video files are downloaded, and no watch history, subscriptions, comments, contacts or payment data are accessed.

Storage: OAuth tokens and results are stored only in the app folder on the operator's computer, with tokens encrypted by the operating system (Windows DPAPI). Nothing is sent to the developer's or any third-party server.

Sharing: Google user data is never sold, shared with third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revocation and deletion: disconnect the channel in the app or revoke access at Google Account → Third-party access. Deleting the app folder removes all stored tokens and results.
